# Basic Informational Site

A basic informational website built as part of my journey learning **Node.js and backend development**.

The main goal of this project is to understand how to create an HTTP server using Node.js, handle incoming requests, work with file paths, and serve HTML pages depending on the requested URL.

## What I'm Learning

- Creating an HTTP server using Node.js's built-in `http` module.
- Handling HTTP requests and responses.
- Working with the `fs` module to read HTML files.
- Using the `path` module to resolve file paths safely.
- Understanding URL routing and serving different pages based on the requested URL.
- Setting HTTP status codes and handling 404 errors.
- Organizing a basic multi-page website.

## Pages

- **Home** — `index.html`
- **About** — `about.html`
- **Contact** — `contact-me.html`
- **404 Error** — `404.html`

## Technologies

- HTML5
- JavaScript
- Node.js

## How to Run

1. Make sure Node.js is installed.
2. Clone this repository.
3. Navigate to the project directory.
4. Start the server:

   ```bash
   node index.js
   ```

5. Open `http://localhost:8080` in your browser (or use the port configured in the server).

## Project Goals

This project is part of my ongoing journey into backend development, focusing on understanding the fundamentals of Node.js without relying on external frameworks.
